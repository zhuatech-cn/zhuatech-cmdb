# 企业配置管理数据库企业能力

## 领域覆盖

- **配置项台账**：维护硬件、软件、云资源、应用和业务服务配置项
- **模型与分类**：定义配置项类型、属性模板、唯一键和生命周期
- **自动发现**：接收扫描、云平台和监控工具发现结果并完成归并
- **关系管理**：维护依赖、部署、连接、承载和上下游关系
- **服务映射**：将配置项关联至业务服务、组织和服务负责人
- **配置基线**：保存批准基线、差异快照和合规检查结果
- **变更校验**：在变更前执行影响分析并在变更后核对配置
- **数据质量**：治理重复、孤立、过期、无责任人和属性缺失配置项
- **审计追踪**：记录发现、合并、变更、导出和管理员操作证据

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业配置管理数据库关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `ITSM`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
